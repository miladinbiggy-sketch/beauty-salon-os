# V5 实际门店验收清单

在测试数据库/隔离域名执行，不要直接用真实顾客资料做压测。

1. **分辨率**：360px 手机、768px 平板、1440px 桌面打开店长工作台和顾客预约；手机导航、弹窗、服务卡片不能溢出。
2. **语言**：中日语言切换后，预约、收银、客户以及顾客页面的内容应一致且不丢失已填写表单。
3. **排单**：创建一笔60分钟美甲预约，确认日/周视图、接待清单、预约详情均可显示；关闭再开页面后数据仍存在。
4. **误操作**：鼠标/触屏拖动已预约块到新位置→必须弹确认；点击取消后原预约时间不变。
5. **确认改期**：点击确认后 API 检查工位、员工和休息时间；冲突返回409且原预约不变；成功后刷新列表。
6. **同槽并发**：两个浏览器并发选择同一技师和单工位，最多只能成功一个；另一个得到冲突反馈。
7. **今日接待**：创建、到店、开始、完成、取消等状态变化后，待服务清单和计数应正确刷新；预计金额不得冒充实收。
8. **顾客改日期**：在日期 A 选一个时间，切换日期 B；下一步不得继续使用 A 的旧时段。
9. **断网**：客户、报表、收银页面模拟 API 失败，应显示错误而不是零元/空记录，恢复后重试成功。
10. **CSV**：日文/中文含逗号、引号、换行的姓名和公式式输入，在 Excel 中正常显示且不能当作公式执行；文件只含当前查询结果。
11. **角色隔离**：技师账号不能访问客户总表、全部收款、报表和设置；检查直接输入路由以及 API 拒绝。
12. **验证旧功能**：V4 的会话吊销、预约硬约束、部分退款/并发退款、多门店隔离回归测试须全部通过。
13. **通知 & 支付**：如果尚未配置真实 LINE／收款商，必须保留模拟或手工确认标识，不能对客户宣称已发送或已扣款。
14. **保护数据**：日常备份、异地恢复、日志脱敏、导出权限管理和信息安全政策确认后才使用真实顾客信息。
