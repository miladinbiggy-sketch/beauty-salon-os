## 安全措施（已落地）

- 密码 scrypt 哈希；JWT（HS256，12h）；登录与公开预约接口限流（滑动窗口）
- RBAC：owner/manager/staff 三级；技师数据面最小化（仅本人日程/业绩、被分配客户、被指派预约）
- 顾客自助查询/取消：预约码 + 手机号双因子校验，查不到统一返回 404 防枚举
- 输入全部经 zod 校验；金额/时长为整数日元/分钟，服务端复核快照
- 审计日志记录关键写操作，写入前脱敏（password/token/phone/email 等）
- 预约防重放/防双击：事务咨询锁 + 排斥约束，重复提交只会得到 409
- 支付只记账：不保存任何银行卡敏感信息
